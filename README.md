# Ensemble Dubai — Pitch Site

Luxury boutique concept site for pitching [Ensemble Dubai](https://www.instagram.com/ensembledxb/) (@ensembledxb).

Their current Shopify storefront at [ensembledubai.com](https://ensembledubai.com/) is password-locked (“Website launching soon”), so this demo shows what a finished digital presence can look like.

## Run

```bash
cd ensemble-dubai
npm install
npm run dev
```

Open [http://localhost:5174](http://localhost:5174).

## Pages

- `/` — hero, boutique story, collections, selected pieces
- `/collections` — filterable gallery + WhatsApp enquire
- `/visit` — villa address, hours, maps
- `/contact` — appointment form → WhatsApp
